# 유가이력 — 화면 명세 및 사용자 스토리텔링

## 1. 사용자 스토리텔링 (화면 흐름 중심)

앱을 켠다.

메인 화면에는 오늘자 가격이 낮은 순으로 주유소들이 정렬되어 있다.

햄버거 버튼을 누른다. 즐겨찾기 창이 열리며, 내가 즐겨찾기 등록해둔 주유소가 나열되어 있다 (최저가순).

리스트 중 특정 주유소를 누른다. 상세 화면으로 전환된다.

상세 화면에는 크게 주유소명 - 주소 - 즐겨찾기 등록 버튼 - 그래프가 순서대로 보인다.

화면에는 유종 변경 토글 버튼(휘발유/경유)이 있고, 기본으로 휘발유가 선택되어 있다.

화면 중심에는 그래프가 있고, 그래프에는 기본으로 30일 가격 추이 선이 그려져 있다. 그 위에는 7일 이동평균선이 겹쳐져 있다.

메인 텍스트에는 "오늘 가격, 7일 평균 대비 -40원"과 같이 평균 대비 가격이 어떤지 나와있다.

그래프는 30일 - 7일 전환이 가능하다 (기본값 30일). 평균선 설정도 7일 - 30일 전환이 가능하다 (기본값 7일).

평균선을 바꾸면 메인 텍스트의 기간도 함께 바뀐다.

## 2. 데이터 범위

- 학교 반경 N km 내 주유소로 수집 대상 고정 (GPS 실시간 조회 없음)
- 하루 1회 수집
- 유종 2종 (휘발유 / 경유)

## 3. 첫 화면

- 메인 리스트: 오늘자 가격이 낮은 순으로 주유소 정렬
- 햄버거 버튼 클릭 시 즐겨찾기 드로어(우측 슬라이드 패널) 오픈
  - 등록해둔 주유소를 최저가순으로 나열

## 4. 상세 화면

레이아웃 순서 (상단 → 하단):

1. 주유소명
2. 주소
3. 즐겨찾기 등록 버튼 (별 아이콘)
4. 그래프

세부 기능:

- **유종 토글**: 휘발유 / 경유 전환 (기본값: 휘발유), 전환 시 그래프 데이터 갈아끼움
- **그래프**: 가격 추이 선 그래프
  - 기간 전환: 7일 / 30일 (기본값: 30일)
  - 이동평균선: 7일 / 30일 (기본값: 7일), 그래프 위에 겹쳐 표시
  - 평균선 기간 변경 시 메인 텍스트의 기간도 동기화되어 함께 바뀜
- **메인 텍스트**: "오늘 가격, [평균선 기간]일 평균 대비 [+/-]원" 형식으로 표시
- **지도**: 여유 시 추가 (프로젝트 전체 차원 결정 대기 — 잇썸과 공통 이슈)
