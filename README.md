# 발자국 — 조별과제 과정기록 & 평가지원 서비스

AI소프트웨어과 · 시스템설계 · 2026-2학기 · 3조

조별과제의 산출물과 완료확인을 과정 기록으로 남기고, 그 근거를 보면서 사람이 동료평가를 입력하는 PC 웹 서비스.
원칙: **판단은 사람이 하고, 시스템은 근거만 보여준다.** 점수 자동 계산, 순위, 가중치는 없다.
